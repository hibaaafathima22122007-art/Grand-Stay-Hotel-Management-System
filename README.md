# Grand Stay — Hotel Management System

A Java-based hotel management web application developed for the CS23304 Java Programming mini project.

## Features
- Admin login and session-based access protection
- Dashboard with hotel statistics
- Room management
- Guest registration and management
- Booking creation, date validation, room availability checks, and cancellation
- Bill generation and payment status tracking
- Reports for hotel operations and billing

## Technology Stack
- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- JDBC / JdbcTemplate
- MySQL
- Maven
- HTML and CSS
- Git and GitHub

## How to Run
1. Install a compatible JDK and MySQL Server.
2. Create the `hotel_management` database and required tables.
3. Configure your local database credentials.
4. Open the project in IntelliJ IDEA and allow Maven to load dependencies.
5. Run `HotelManagementWebApplication.java`.
6. Open `http://localhost:8080` in your browser.
7. Log in using the administrator account configured in your database.
